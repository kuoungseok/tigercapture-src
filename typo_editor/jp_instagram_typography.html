🎯 SVG 구현 핵심 포인트

• 글자 단위 분리 — <tspan>으로 문자별 애니메이션
• 세로쓰기 — writing-mode: vertical-rl (CSS)
• 한자 자동 감지 — Unicode 범위 U+4E00-9FFF로 판별해 자동 스타일 적용
• SVG Path 애니메이션 — 붓글씨는 stroke-dasharray로 획 그려지는 효과
• filter — 먹물 번짐, 네온 빛 번짐 등은 SVG filter로 구현

🇯🇵 일본 스타일 핵심 원칙

• 여백(間)이 디자인 — 글자 간격, 줄간격 넉넉히
• ずらし(즈라시) — 글자마다 시간차, 완벽한 동기화 피하기
• 한자 강조 — 크기/색상으로 한자를 시각적 앵커로
• 명조체 기본 — Noto Serif JP, Yu Mincho (세리프가 일본 감성)
• 붉은색 액센트 — 한자나 중요 요소에 붉은색 (일본 감성)

📱 인스타 스타일 핵심 원칙

• 2-3초 완결 — 숏폼은 빨라야 함. 애니메이션 전체 3초 이내
• 반복 가능한 루프 — 인스타는 자동 반복 재생됨
• 세로형 우선 — 9:16 비율 염두
• 이모지 친화적 — 이모지도 1급 시민으로 취급
• 굵은 산세리프 — Impact, Druk, Helvetica Neue Condensed
• 컬러 대담하게 — 흑백 극단 또는 무지개 그라데이션

💡 한국 크리에이터에게 매력적인 이유

• 일본 애니메이션/드라마 시청자 많음 (특히 20-30대)
• 한자 병기 콘텐츠(학습/여행) 많음
• 인스타/릴스 사용자 매우 많음
• 기존 영상 편집 툴에 이 카테고리가 부실함 (곰믹스, Vrew도 약함)
• 차별화 포인트로 강력!
