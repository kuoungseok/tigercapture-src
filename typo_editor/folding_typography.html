折れる / 曲がる タイポグラフィ

글자가 꺾이는 9가지 애니메이션 스타일 — CSS 3D Transform + SVG Path

📄 종이접기 (Paper Fold) EASY
FOLD FOLD
글자가 중앙에서 반으로 접혀 등장. clip-path: inset() + rotateX() 조합. 편지지가 펴지는 느낌.
🦿 관절 꺾임 (Joint Break) EASY
BEAT!
글자들이 관절처럼 꺾임. 비트에 맞춰 개별 회전. transform-origin: bottom으로 밑동 고정. EDM/록에 잘 어울림.
❭❬ 꺾쇠 출현 (Bracket Appear) EASY
【 重要 】
일본식 꺾쇠가 회전하며 등장 → 중앙에 텍스트 팝업. 니코니코 자막의 정석. "【중요】" 같은 강조 표시.
🎲 3D 플립 (Card Flip) EASY
FLIP
글자가 Y축으로 360도 회전하며 색상 변화. perspective + rotateY(). 카드 뒤집히는 느낌.
💥 조각 꺾임 (Shatter) MEDIUM
割
글자가 대각선으로 두 조각나며 꺾임. clip-path: polygon()로 조각 분할. 유리 깨짐 + 분리. "割れる(깨지다)" 표현.
🚩 깃발 웨이브 (Flag Wave) EASY
風に揺れる旗
글자들이 바람에 깃발처럼 펄럭. 순차 rotateY() + translateZ()로 입체감. 서정적 가사에 어울림.
🪗 아코디언 접힘 (Accordion) MEDIUM
ACCORD
글자가 좌우 교대로 꺾이며 접힘. 홀수 번째는 왼쪽, 짝수 번째는 오른쪽 기준. 아코디언 펼쳐지는 느낌.
📈 획 구부러짐 (SVG Morph) HARD
PATH MORPH
SVG Path의 좌표가 실시간으로 변형. @keyframes에서 d: 속성 직접 애니메이션. 가장 복잡하지만 가장 독특.
⚡ 각도 꺾임 (Angle Break) EASY
狂 う 世 界 !
각 글자의 회전축이 다름 (왼쪽 아래, 오른쪽 위 등). 개별 글자가 서로 다른 방향으로 꺾이며 리듬감. 우타이테 MV 시그니처!

🎯 구현 팁

  • 기본 원리: transform 속성 중 rotate, skew, perspective 조합
  • 글자 분리: JavaScript로 text.split('').map(ch => <span>{ch}</span>)
  • 순차 딜레이: animation-delay: {i * 0.1}s로 타이밍 조절
  • 회전 축 조절: transform-origin: left bottom 등으로 꺾이는 지점 설정
  • 3D 효과: 부모에 perspective: 1000px 필수
  • SVG Morph: GSAP의 MorphSVG 플러그인이나 CSS Houdini 사용

🎵 우타이테 MV에 특히 잘 어울리는 것

  • ⚡ 각도 꺾임: 감정 폭발 구간, 드롭, 사비
  • 🦿 관절 꺾임: 비트 싱크, 리듬감 있는 구간
  • ❭❬ 꺾쇠 출현: 중요한 단어 강조, 자막
  • 💥 조각 꺾임: 파괴적 가사 ("割れる", "壊す" 등)
  • 🚩 깃발 웨이브: 잔잔한 간주, 서정적 가사

🚀 고급 응용 아이디어

1. 비트 싱크 꺾임

오디오 비트 감지 → 킥 드럼 때마다 글자가 짧게 꺾임. Web Audio API의 AnalyserNode로 저역 에너지 감지.

2. 한자/가나 차등 꺾임

한자는 크게 꺾이고, 히라가나/가타카나는 작게 떨림. Unicode 범위로 자동 판별.

3. 깨지는 단어 자동 감지

가사에 "割れる", "壊れる", "砕く" 같은 단어 감지 → 자동으로 조각 꺾임 효과 적용.

4. 조합 효과

여러 꺾임을 동시에: 예) 깃발 웨이브 + 색상 변화 + 글리치. 레이어링으로 복잡한 효과 생성.

5. 3D 공간 배치

translate3d()로 각 글자를 서로 다른 Z 거리에 배치 → 꺾이면서 원근감 생김. 가장 임팩트 큼.
