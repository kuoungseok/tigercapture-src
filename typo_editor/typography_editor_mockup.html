🎬 주요 기능

• 텍스트 트랙 추가 — 비디오/오디오 트랙과 동일 구조, T 아이콘 드래그로 클립 생성
• 클립 길이 = 애니메이션 길이 — 가장자리 드래그로 조절
• 더블클릭으로 에디터 오픈 — 3-pane 레이아웃 (Text / Animation / Style)
• In-Hold-Out 3단계 — After Effects 구조 차용
• 카테고리별 프리셋 — Basic/Text/Kinetic/Cinema/Trend
• AI 자동 추천 — 텍스트 내용 분석해서 어울리는 애니메이션 제안
• 한국 스타일 프리셋 — 예능자막/뉴스자막/드라마/Vlog

🚀 차별화 포인트

• 카테고리 5탭 — 초보자 친화적 (CapCut 방식)
• AI 추천 — 텍스트 분석 기반 (다른 툴엔 없음)
• 한국 예능 자막 — 한국 시장 특화 (Vrew, 곰믹스보다 디테일)
• 템플릿 저장/공유 — 사용자 자산 축적
• In-Hold-Out 분리 — 자막과 키네틱 타이포그래피 모두 지원

🎨 디자인 원칙

• 텍스트 트랙 = 보라/주황 그라데이션 (비디오=파랑, 오디오=초록과 구분)
• In/Hold/Out = 초록/파랑/주황 (단계별 시각화)
• 프리뷰는 실제 검정 배경 (영상 위에 얹히는 느낌 재현)
• 3-pane (텍스트 / 애니메이션 / 스타일 명확 분리)
