# Painter UI M1 공식 튜토리얼 증거표

이 문서는 Painter UI의 M1 구현을 추측으로 확장하지 않기 위한 작업 기준이다.
각 동작은 공식 Figma 도움말의 화면 순서와 설명에서 확인된 뒤에만 구현한다.

## 기준 자료

- 공식 도움말: [Select layers and objects](https://help.figma.com/hc/en-us/articles/360040449873-Select-layers-and-objects)
- 공식 도움말: [Adjust alignment, rotation, position, and dimensions](https://help.figma.com/hc/en-us/articles/360039956914-Adjust-alignment-rotation-position-and-dimensions)
- 확인일: 2026-08-03

## 공식 화면 순서

### M1.1 캔버스 기본 선택 — 구현 및 자동 검증 완료

1. 객체를 한 번 클릭하면 선택한다.
2. 중첩 객체를 한 번 클릭하면 먼저 부모를 선택한다.
3. 같은 위치를 더블클릭하거나 Enter를 누르면 정확히 한 단계 아래 자식을 선택한다.
4. Windows에서 Ctrl+클릭하면 포인터 아래의 중첩 객체를 직접 선택한다.
5. Shift+클릭은 객체를 다중 선택에 추가하고, 이미 선택한 객체에서는 제거한다.
6. 빈 캔버스에서 드래그하면 선택 영역을 만든다.
7. 일반 선택 영역은 최상위 레이어를 대상으로 한다.
8. Windows에서 Ctrl+드래그하면 중첩 레이어도 선택 영역에 포함한다.
9. Esc는 선택을 해제한다.
10. 숨김 객체와 잠긴 객체는 일반 캔버스 클릭 대상으로 삼지 않는다.

자동 검증:

- `tests/test_painter_ui_selection_tutorial.py`
- 부모 선택과 Ctrl 깊은 선택
- Shift 토글
- 더블클릭/Enter 한 단계 진입
- 일반 마키와 Ctrl 중첩 마키
- Esc 선택 해제

### M1.2 선택 계층 탐색 — 구현 및 자동 검증 완료

공식 화면에서 확인하고 구현한 순서:

1. Shift+Enter로 부모를 선택한다.
2. Tab으로 다음 형제 레이어를 선택한다.
3. Shift+Tab으로 이전 형제 레이어를 선택한다.
4. 우클릭 후 `Select layer` 하위 메뉴에서 포인터 아래 레이어를 고른다.
5. 이 메뉴의 순서는 Layers 패널 순서와 일치한다.
6. 숨김 레이어는 `Select layer` 메뉴에서 제외한다.
7. 잠긴 레이어는 일반 클릭으로 선택하지 못하지만 `Select layer` 메뉴에는 잠금 아이콘과 함께 포함한다.

자동 검증:

- 부모·다음 형제·이전 형제 키보드 이동
- Layers 패널과 동일한 계층·z 순서
- 숨김 제외와 잠금 포함
- 실제 캔버스 우클릭 위치에서 `Select layer` 메뉴 구성 및 객체 선택

### M1.3 Layers 패널 연동 — 구현 및 자동 검증 완료

공식 화면에서 확인된 다음 순서:

1. Layers 패널 항목을 가리키면 캔버스 객체가 파란색으로 강조된다.
2. Shift+클릭은 연속 범위를 선택한다.
3. Ctrl+클릭은 떨어진 항목을 개별 선택한다.
4. 캔버스와 Layers 패널은 같은 object ID 선택을 공유한다.

자동 검증:

- 실제 표시된 Layers 패널 행 호버와 캔버스 파란 윤곽 대상 ID
- Shift+클릭 연속 범위 선택
- Ctrl+클릭 개별 선택 토글
- Layers 패널에서 PaintDialog 캔버스 오버레이까지 동일 object ID 전달

### M1.4 이동·크기 조절·기본 정렬 — 구현 및 자동 검증 완료

공식 화면에서 확인하고 구현한 순서:

1. 선택 객체는 모서리와 네 변의 핸들을 드래그해 크기를 조절한다.
2. 모서리 핸들은 너비와 높이를 함께, 변 핸들은 해당 축을 조절한다.
3. Shift를 누른 크기 조절은 기존 가로세로 비율을 유지한다.
4. 객체 이동과 크기 조절 중 다른 객체의 중심·외곽점에 스냅하고 빨간 가이드를 표시한다.
5. 객체 스냅과 격자 단위 스냅은 서로 독립된 설정이다.
6. 화살표 키는 선택을 1만큼 이동하고 Shift+화살표는 10만큼 이동한다.
7. 여러 객체가 선택되면 키보드 이동은 전체 선택에 적용한다.
8. 단일 객체 정렬은 해당 객체의 부모 프레임을 기준으로 한다.
9. 다중 객체 정렬은 선택 객체들의 바깥 경계를 기준으로 한다.
10. 공식 Windows 정렬 단축키 Alt+A/H/D/W/V/S를 지원한다.

자동 검증:

- `tests/test_painter_ui_transform_tutorial.py`
- 모서리 4개와 변 4개의 총 8개 크기 조절 핸들
- 변 핸들 축별 조절과 Shift 비율 유지
- 부모 프레임 기준 단일 정렬
- 다중 선택 1/10 단위 키보드 이동
- 객체 스냅과 격자 스냅 설정 분리
- 공식 여섯 정렬 단축키 전달
- `tests/test_painter_ui_smart_guides.py`
- 이동·크기 조절 중심/외곽점 스냅 계획

별도 구현·검증된 공식 항목:

- 배분과 Tidy up은 M1.6a/M1.6b에서 검증한다.
- 비율 잠금과 인스펙터 값 scrub은 `painter_ui_constraints`,
  `painter_ui_numeric_input`, `painter_ui_inspector_properties` 테스트로 검증한다.

### M1.5 회전 — 구현 및 자동 검증 완료

공식 화면에서 확인하고 구현한 순서:

1. 선택 객체의 회전 조작점은 기본적으로 선택 중심을 회전 원점으로 사용한다.
2. 조작점을 드래그하면 객체가 포인터 방향을 따라 회전한다.
3. Figma 인스펙터와 같이 양수 각도는 반시계, 음수 각도는 시계 방향이다.
4. 각도는 -180°부터 180° 범위로 정규화한다.
5. Shift를 누른 동안에만 15도 단위로 스냅한다.
6. 격자 스냅 설정은 회전 15도 스냅을 대신하지 않는다.
7. 다중 선택은 공통 선택 경계의 중심을 원점으로 모든 객체를 함께 회전한다.
8. 회전 중 현재 각도를 파란 라벨로 표시한다.

자동 검증:

- 단일 선택 시계 방향 음수 각도
- Shift 15도 스냅과 일반 연속 각도
- 격자 스냅과 회전 스냅의 독립성
- 다중 선택 공통 중심 회전과 일괄 변경 전달
- 사용자 지정 피벗의 Figma식 각도 역변환
- 매우 작은 배율에서 룰러보다 객체 조작점을 우선하는 입력 순서

### M1.6a 1차원 배분과 Tidy up — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인하고 구현한 순서:

1. 가로 간격 배분은 가장 왼쪽과 가장 오른쪽 객체의 위치를 유지한다.
2. 세로 간격 배분은 가장 위와 가장 아래 객체의 위치를 유지한다.
3. 그 사이 객체만 이동해 인접 객체 사이의 간격을 동일하게 만든다.
4. Tidy up은 기존 선택 경계 안에 맞추는 배분과 달리 첫 객체에서 시작해 객체를 다시 배열한다.
5. 1차원 Tidy up은 선택의 다른 축을 강제로 정렬하지 않는다.
6. Tidy up의 기본 간격은 평균이 아니라 선택에서 가장 흔한 간격값을 사용한다.
7. 픽셀 격자 반올림으로 1px 차이가 나는 간격은 같은 표시 간격으로 취급한다.
8. 배분과 Tidy up은 모두 한 번의 일괄 변경 및 한 번의 실행 취소 단위로 적용한다.

자동 검증:

- 가로 배분 시 양쪽 바깥 객체 고정
- 서로 다른 크기의 객체 사이 동일 간격 계산
- Tidy up 기본 간격의 최빈값 선택
- 19px/20px 픽셀 반올림 간격 허용
- 명시적 간격 Tidy up과 단일 실행 취소
- 잠금 객체 및 서로 다른 부모 선택 차단

다음 하위 단계:

- M1.7 Smart selection의 분홍색 간격 핸들, 간격 드래그, 객체 재정렬

### M1.6b 2차원 Tidy up — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인한 외부 동작:

1. 선택 객체들이 한 축에서 서로 겹치면 기존 1차원 행 또는 열로 판정한다.
2. 어느 한 축의 단일 행·열로도 묶이지 않는 선택만 2차원 그리드로 판정한다.
3. 2차원 Tidy up은 가로와 세로 간격을 모두 조정한다.
4. 가로와 세로 간격은 시작 위치에 따라 같거나 서로 다를 수 있다.
5. 배분과 달리 기존 선택 영역에 억지로 맞추지 않고 선택의 좌상단에 그리드를 맞춘다.

Painter 내부 구현 매핑(Figma 내부 알고리즘이라고 주장하지 않음):

1. 원래 화면상의 위→아래 행 순서와 왼쪽→오른쪽 열 순서를 유지한다.
2. 객체가 겹치지 않도록 각 열의 최대 너비와 각 행의 최대 높이로 다음 셀 위치를 계산한다.
3. 원래 선택에서 가장 흔한 가로 간격과 세로 간격을 각각 초기값으로 사용한다.
4. 오른쪽 다중 선택 인스펙터에는 `H`와 `V` 간격값을 별도로 표시하고 적용한다.
5. 전체 그리드 변경은 한 번의 일괄 변경 및 한 번의 실행 취소 단위로 처리한다.

자동 검증:

- 단일 행·열과 2차원 그리드 판정 분리
- 불규칙한 초기 위치의 시각적 행·열 순서 보존
- 선택 좌상단 원점 유지
- 열 최대 너비 및 행 최대 높이를 반영한 배치
- 서로 다른 가로·세로 간격 적용
- 다중 선택 인스펙터 `H`/`V` 값과 요청 payload

### M1.7a Smart selection 간격 핸들 — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인한 외부 동작:

1. 두 개 이상의 선택 객체가 같은 간격이고 한 축(1D) 또는 두 축(2D)에서 겹칠 때 Smart selection이 된다.
2. 간격이 균등하지 않으면 먼저 Tidy up으로 Smart selection을 만들 수 있다.
3. Smart selection의 각 객체 중심에는 분홍색 링이 표시된다.
4. 선택 영역에 마우스를 올리면 객체 사이에 분홍색 간격 핸들이 추가로 나타난다.
5. 가로 핸들을 오른쪽으로 드래그하면 가로 간격이 증가하고 왼쪽이면 감소한다.
6. 세로 핸들을 아래로 드래그하면 세로 간격이 증가하고 위쪽이면 감소한다.
7. 드래그 중 현재 간격의 픽셀값을 포인터 옆 분홍색 라벨로 표시한다.
8. 2차원 선택은 가로와 세로 간격 핸들을 모두 제공한다.
9. 드래그를 놓으면 선택 전체의 위치 변경을 한 번의 일괄 변경으로 적용한다.

자동 검증:

- 불균등 간격 선택에서 Smart selection 비활성화
- 균등한 1차원 행에서 객체 중심 링 조건과 가로 간격 핸들 생성
- 가로 간격 핸들 드래그 방향 및 동일 간격 유지
- 드래그 중 픽셀 라벨과 포인터 위치 갱신
- 2차원 그리드의 가로·세로 핸들 동시 제공
- 마우스 릴리스 시 단일 batch payload

다음 하위 단계:

- M1.7c 표시 항목 복제·삭제·크기 변경 후 동일 간격 reflow

### M1.7b Smart selection 표시와 1차원 재정렬 — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인한 외부 동작:

1. 객체 중앙의 분홍색 링을 클릭하면 해당 항목을 표시(mark)한다.
2. 표시된 항목의 중앙 링은 속이 찬 분홍색 원으로 바뀐다.
3. 1차원 Smart selection에서는 Shift+클릭으로 여러 항목을 표시할 수 있다.
4. 표시한 항목을 행 또는 열의 다른 위치로 드래그할 수 있다.
5. 드래그 중 파란색 삽입 표시가 놓일 위치를 보여준다.
6. 놓으면 표시한 항목의 화면상 순서가 바뀌고 나머지 항목이 같은 간격으로 재배치된다.
7. 여러 표시 항목을 옮길 때 항목 사이의 기존 상대 순서를 유지한다.
8. Smart selection 재정렬은 Layers 패널의 레이어 계층 순서를 변경하지 않는다.

자동 검증:

- 중앙 링 클릭 시 단일 표시와 속이 찬 링 상태
- 1차원 Shift+클릭 다중 표시
- 드래그 임계값 전에는 위치 변경 없음
- 드래그 중 파란 삽입 표시
- 행의 첫 위치로 재정렬 후 동일 간격 유지
- 재정렬 batch payload 1회
- 문서 객체/레이어 배열 순서 불변

다음 하위 단계:

- M1.7c 표시 항목 복제·삭제·크기 변경 후 동일 간격 reflow

### M1.7b-2 2차원 Smart selection 재정렬 — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인한 외부 동작:

1. 2차원 Smart selection에서는 한 번에 한 레이어만 재정렬한다.
2. 객체 중앙의 분홍색 링을 잡아 다른 위치로 드래그한다.
3. 기본 드래그는 2차원 선택을 `목록 안의 목록`처럼 취급하여 기존 행 또는 열에 객체를 삽입한다.
4. 드래그 중 파란색 표시는 객체가 놓일 위치를 보여준다.
5. Windows에서 Ctrl을 누른 채 다른 객체 위치로 드래그하면 두 객체의 위치를 교환한다.
6. 재정렬 후에도 Layers 패널의 레이어 계층 순서는 바뀌지 않는다.

우리 구현의 결정론적 배치 계산:

- 이 계산은 공개된 Figma 내부 알고리즘이라고 주장하지 않는다. 위 공식 외부 동작을 재현하기 위한 Painter 내부 규칙이다.
- 시각적 Y 겹침으로 행 목록을 만들고, 각 행에서는 X 순으로 객체를 정렬한다.
- 기본 드래그는 포인터에 가장 가까운 행을 선택한 뒤 객체 중심 X를 기준으로 삽입 열을 결정한다.
- 삽입 뒤에는 기존 Smart selection의 가로·세로 간격, 열별 최대 너비, 행별 최대 높이를 사용해 다시 배치한다.
- Ctrl 드래그는 포인터에 가장 가까운 다른 객체와 두 시각적 슬롯의 객체 ID를 교환한다.
- 화면상 위치만 바꾸며 문서 객체 배열과 레이어 계층 순서는 유지한다.

자동 검증:

- 2×2 Smart selection에서 기존 행 안으로 단일 객체 삽입
- 삽입 후 가로·세로 동일 간격과 계층 순서 유지
- Ctrl 드래그 대상의 파란색 교환 윤곽 표시
- Ctrl 위치 교환 후 두 슬롯의 좌표 교환
- 한 객체만 있는 행에서 다른 행으로 옮겨도 삽입 표시와 배치가 깨지지 않음
- 마우스 릴리스 시 단일 batch payload

공식 근거:

- https://help.figma.com/hc/en-us/articles/360040450233-Arrange-layers-with-Smart-selection

### M1.7c Smart selection 복제·크기 변경·삭제 reflow — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인한 외부 동작:

1. 표시한 레이어는 Windows `Ctrl+D`로 복제하며 여러 레이어도 함께 복제할 수 있다.
2. 1D 가로 선택의 복제본은 원본 오른쪽, 1D 세로 선택은 원본 아래에 놓인다.
3. 2D 선택의 복제본은 원본 아래에 놓이고 다른 레이어가 자리를 만든다.
4. 크기 변경 뒤에도 레이어 사이의 동일 간격을 유지하도록 나머지 레이어가 이동한다.
5. 2D에서는 한 레이어, 1D에서는 여러 레이어의 크기를 바꿀 수 있다.
6. 표시한 레이어는 Delete 또는 Backspace로 삭제하며 나머지가 빈자리를 채운다.
7. 1D 가로는 왼쪽, 1D 세로는 위쪽, 2D는 위쪽으로 빈자리를 채운다.

우리 구현의 결정론적 배치 계산:

- 1D는 기존 시각 순서에 복제본을 원본 바로 다음에 삽입하고 원래 간격으로 다시 배치한다.
- 2D 복제·삭제는 시각적 열 목록을 유지하며 해당 열에서 아래로 삽입하거나 위로 압축한다.
- 2D 크기 변경은 행의 최대 높이와 열의 최대 너비를 다시 계산해 다음 행·열을 이동한다.
- 이 계산은 공개된 Figma 내부 알고리즘이 아니라 공식 외부 결과를 재현하기 위한 Painter 내부 규칙이다.
- 복제·삭제·크기 변경 각각을 한 번의 undo 가능한 batch 변경으로 적용한다.

자동 검증:

- 1D 복제본의 원본 다음 위치 및 뒤 레이어 이동
- 2D 삭제 후 같은 열의 아래 레이어가 위로 이동
- 2D 단일 레이어 높이 변경 후 다음 행이 기존 간격 유지
- 표시 레이어 개별 리사이즈 핸들 및 reflow 경로
- Delete와 Backspace 명령 경로

공식 근거:

- https://help.figma.com/hc/en-us/articles/360040450233-Arrange-layers-with-Smart-selection

### M1.8 Smart selection 전체·축 단위 표시 — 구현 및 자동 검증 완료

공식 Figma 문서에서 확인한 외부 동작:

1. 1D Smart selection에서는 아무 레이어를 더블클릭하면 모든 레이어를 표시한다.
2. 2D Smart selection에서는 Shift를 누른 채 레이어를 더블클릭하면 같은 축의 레이어를 표시한다.
3. 이어서 다시 더블클릭하면 2D 선택의 모든 레이어를 표시한다.
4. 표시된 레이어의 중앙 Smart handle은 속이 찬 분홍색 원으로 보인다.

우리 구현의 결정론적 축 판정:

- 공개 문서는 2D의 `같은 축`을 어떤 내부 셀 계산으로 정하는지 설명하지 않는다.
- Painter는 시각적 Y 겹침으로 만들어진 동일 행을 첫 번째 축 단위로 사용한다.
- 같은 행이 이미 표시된 상태에서 다시 더블클릭하면 전체 표시로 승격한다.
- Smart selection이 활성화되지 않은 경우 기존 텍스트 편집과 계층 진입 더블클릭을 그대로 유지한다.

자동 검증:

- 1D 레이어 더블클릭 후 전체 중앙 링 표시
- 2D Shift+더블클릭 후 동일 시각 행만 표시
- 같은 행 표시 상태의 재더블클릭 후 전체 표시
- Smart selection 외부 더블클릭 경로와의 우선순위 분리

공식 근거:

- https://help.figma.com/hc/en-us/articles/360040450233-Arrange-layers-with-Smart-selection

### M1.9 Smart selection 상호작용 회귀 계약 — 구현 및 자동 검증 완료

이 단계는 새 Figma 기능을 추가하지 않는다. M1.7~M1.8에서 공식 문서로
확인한 조작들이 연속 작업에서 충돌하지 않도록 제품 계약을 고정한다.

고정한 계약:

1. 일반 다중 선택과 Smart selection 표시 상태를 구분한다.
2. Smart 표시 ID는 화면상 안정 순서로 컨트롤러에 전달하며 private 상태를 직접 읽지 않는다.
3. Ctrl+D는 복제, Delete와 Backspace는 삭제로 서로 다른 명령을 유지한다.
4. 더블클릭으로 표시 범위를 바꾸면 대기 중이던 재정렬 interaction을 종료한다.
5. 문서 선택이 바뀌면 새 선택 밖의 표시 ID를 즉시 제거한다.
6. Smart selection이 사라진 상태에서는 표시 ID를 외부 mutation 대상으로 노출하지 않는다.
7. 각 복제·삭제·리사이즈·재정렬은 한 번의 Undo batch로만 확정한다.

자동 검증:

- 표시 ID의 시각 순서 공개 API
- Ctrl+D와 Backspace 명령 분리
- 더블클릭 뒤 재정렬 대기 상태 해제
- 선택 계약 변경 뒤 stale 표시 ID 제거
- Smart selection 비활성화 시 빈 표시 목록
- 기존 선택·변형·액션·아키텍처 회귀 묶음

스펙 반영:

- 루트 `SPEC.md`의 Painter UI Design selection 계약에 일반 다중 선택과
  Smart selection 예외, 키보드 명령, reflow 및 Undo 경계를 기록했다.
