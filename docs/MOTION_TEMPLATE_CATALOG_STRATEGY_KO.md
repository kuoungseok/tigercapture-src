# Motion Designer 실사용 템플릿 전략

## 목표

템플릿은 빈 캔버스의 장식 예제가 아니라 사용자가 자기 문구와 미디어만
교체해 결과물을 완성할 수 있는 작업 시작점이어야 한다.

Figma의 UI kit처럼 다음 요소를 한 묶음으로 제공한다.

- 여러 장면과 실제 작업 순서
- 반복 사용 가능한 구성 요소와 상태
- 교체해야 할 문구, 미디어, 색상, CTA 목록
- 가로·세로 화면 변형
- 편집 가능한 레이어, 키프레임, 그룹
- 템플릿이 어떤 결과물에 적합한지 설명하는 갤러리 정보

특정 회사의 공식 디자인 리소스를 복제하거나 포함하지 않는다. 현재
`iOS App UI Motion Kit`은 Apple 공식 UI kit가 아니라 모바일 시스템 UI의
구성과 안전 간격을 참고한 Tiger Studio 자체 템플릿이다.

## 현재 구현된 실사용 묶음

### UI & Product

- `iOS App UI Motion Kit`: 24초, 5장면. 상태바, 내비게이션, 카드, 빠른
  동작, 검색, 리스트, 진행 상태, 토글, 알림, 바텀시트, 탭바, 완료 CTA.
- `Mobile Onboarding Flow`: 15초, 4장면. 환영, 권한 설명, 개인화, 완료.
- `Responsive SaaS Product Tour`: 20초, 4장면. 개요, 분석, 협업, 가입 CTA.

### Advertising

- `Product Launch Ad`: 15초, 5장면.
- `Vertical Social Ad`: 15초, 5장면.
- `Campaign Story Ad`: 30초, 6장면.

세 템플릿 모두 훅, 미디어 교체 영역, 효익, 증거, 오퍼와 CTA를 장면
목적에 맞게 나눈다.

### Education

- `Course Module Opener`: 20초, 4장면.
- `Step-by-Step Tutorial`: 45초, 6장면.
- `Lesson Explainer`: 60초, 8장면.

교육 묶음은 학습 목표, 단계 표시, 데모 미디어, 체크리스트, 비교,
지식 확인, 요약 및 다음 학습 장면을 제공한다.

1. UI & Product 확장
   - Android/Material 기반 모바일 흐름
   - 웹사이트 랜딩 페이지와 반응형 상태
   - 전자상거래 상품 상세/장바구니/결제
   - 게임 HUD, 설정, 인벤토리, 퀘스트, 대화
   - 방송 오버레이, 채팅, 알림, 스코어보드
2. Advertising 확장
   - 앱 설치, 패션/뷰티, 자동차, 게임 출시, 행사 프로모션
   - 6초 범퍼, 10초 기사형, 15초 세로형, 30초 브랜드형
   - 가격·할인·리뷰·비교·로고 엔드카드 변형
3. Education 확장
   - 강의 오프너, 소프트웨어 화면 튜토리얼, 문제 풀이
   - 용어 카드, 타임라인, 프로세스, 비교표, 퀴즈
   - 60초 마이크로러닝과 3~5분 챕터 구조

## 품질 통과 조건

- 장면 수와 기본 길이가 갤러리에 표시된 값과 일치한다.
- 장면 경계가 연속이고 첫 장면부터 마지막 장면까지 빈 시간이 없다.
- 모든 장면은 이전 장면과 시각적으로 구분된다.
- 미디어 교체 영역과 텍스트 안전영역이 화면 비율 안에 들어온다.
- 템플릿 적용 후 모든 레이어가 선택·수정·저장·재로드된다.
- Preview와 Export가 같은 시점에서 같은 화면을 만든다.
- `tools/qa_motion_template_catalog.py`가 24개 전체 카탈로그와 다중 장면
  스트립을 실제 renderer로 생성하고 성공해야 한다.
