## Short Positioning

TigerCapture is a local-first Windows creator studio for polished screen
recordings, reviewable AI editing, actor overlays, AR/PBR compositing, optional
local Voice Lab TTS, and alpha VTuber/Broadcast workflows.

## One Paragraph

Record or import a screen video, polish it with Screen Studio-style cursor and
zoom tools, review Creator Assist edit plans before applying them, add actor or
3D overlays, generate optional local subtitle voice clips, and export through a
diagnostic render queue. TigerCapture is strongest where screen recording,
local creator assistance, and timeline-based creative overlays meet.

## Safe Feature Bullets

- Screen Studio-style Auto Polish for measured cursor, click, drag, hotkey, and
  zoom workflows.
- CapCut-style Creator Assist for captions, Shorts planning, vertical reframe,
  publish packages, and render handoff.
- Review-first AI editing through a bottom AI Command dock and Script Edit
  panel, with safe apply instead of hidden timeline mutation.
- Optional local Voice Lab sidecar for subtitle-to-voice generation through a
  connected Style-Bert-VITS2 install.
- Dedicated Live2D, Spine/NIKKE, MMD, and VRM-oriented actor workflows.
- AR/PBR 3D object compositing with HDR/material/shadow/reflection diagnostics.
- Creator-grade color, audio, mask, VFX, and render-readiness foundations.
- QA Dashboard reports for product readiness, public positioning, export parity,
  actor compatibility, Voice Lab sidecar readiness, and long-project health.

## Voice Lab Copy

Voice Lab is optional and local-first. It can connect to an existing
Style-Bert-VITS2 sidecar, synthesize project subtitle rows into aligned WAV
clips, prefer the user's `zoe` model when present, and validate additional local
voice models through a Model Maker bridge. The AGPL TTS engine remains an
external sidecar and is not copied into the closed editor build.

## Claim Boundaries

Use "Screen Studio-style", "CapCut-style", "Descript-lite",
"creator-grade professional foundations", and "optional local sidecar".

Do not claim full replacement or universal parity with Screen Studio, CapCut,
Descript, Premiere, Resolve, Fairlight, Fusion, OBS, Marmoset, Blender, game
engines, hosted TTS platforms, or universal voice-cloning products.
