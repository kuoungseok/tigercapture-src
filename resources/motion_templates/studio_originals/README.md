# Tiger Studio Motion Template Originals

These images are original built-in visual assets created for Tiger Studio's
Motion Designer templates. They are bundled as editable-template media rather
than as a standalone stock-photo collection.

## Assets

- `city_after_rain.png` - `City After Rain`
- `artisan_coffee.png` - `Artisan Coffee Launch`
- `alpine_road.png` - `Alpine Travel Journal`

The images contain no intentional logos, trademarks, watermarks, or identifiable
people. Template users may replace each image through the published
`Background image` media control.
