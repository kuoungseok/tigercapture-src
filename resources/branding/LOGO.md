# Tiger Studio Logo

Official working logo asset:

- `tiger_studio_logo.png`
- `tiger_studio_logo_transparent.png` for startup/loading splash overlays
- `tiger_studio_hero_lockup.png` for the experimental website hero title slot

This file is the current approved Tiger Studio brand image for:

- Studio startup/loading splash
- public GitHub Pages branding
- product README and release-facing documentation
- website or installer artwork that needs a single Tiger Studio mark

Source candidate preserved for traceability:

- `tiger_studio_generated_no_center_character_v22.png`

The transparent version removes only the connected outer black matte while
preserving the tiger's black stripe/linework. Use it anywhere the surrounding UI
already supplies the background.

The hero lockup is optional and rollback-friendly on the public page: remove the
`hero-logo-mode` class from the hero `<header>` to restore the text H1.

Do not point durable product UI at `debugCapture` or temporary generated-image
folders. Keep future approved logo revisions in `resources/branding` and update
this document when the canonical file changes.
